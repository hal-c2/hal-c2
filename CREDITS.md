ledger (`features/`) carries what these people built there. Each is thanked by mention
once, in the HAL-C2 pull request that first carries their work, and listed here. The
[T3 Code Tracker](https://github.com/hal-c2/t3code-tracker-plugin) plugin shows which of
their pull requests the ledger cites and how far HAL-C2 has got with each.

Agents and bots that co-wrote those pull requests are not listed.
